# 主教中国象棋 Bishop Xiangqi

一款基于传统中国象棋规则的变体棋类游戏，特色在于「象/相」的走法采用国际象棋中主教（Bishop）的规则。游戏内置 AI 对战引擎，支持多种难度，纯前端实现，开箱即玩。

## 游戏特色

- **变体规则**：象/相的走法同国际象棋主教，沿斜线任意格移动，不可越子，可过河
- **AI 对战**：基于 Minimax 算法 + Alpha-Beta 剪枝，提供简单 / 中等 / 困难三档难度
- **双人对战**：支持人机对战 (PVC) 与双人对战 (PVP) 模式切换
- **悔棋功能**：可撤销上一步走棋
- **走子提示**：可视化显示上一步走子位置及当前可移动位置
- **重复判和**：三次出现重复局面自动判和
- **响应式布局**：适配桌面与移动端屏幕

## 规则说明

| 规则 | 说明 |
| --- | --- |
| 先手 | 白方先行 |
| 胜负 | 将死或困毙对方获胜 |
| 和棋 | 三次重复局面判和 |
| 象/相 | 沿斜线任意格移动，不可越子，可过河（国际象棋主教走法） |
| 其他棋子 | 车、马、炮、士、将帅、兵卒走法同传统中国象棋 |

## 如何运行

本项目为纯前端实现，无需任何依赖与构建步骤。

### 方式一：直接打开

双击 `index.html` 文件，使用浏览器打开即可。

### 方式二：本地服务器（推荐）

为获得更稳定的加载体验，建议通过本地服务器运行：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js (需先安装 http-server)
npx http-server -p 8000
```

然后浏览器访问 `http://localhost:8000`。

## 操作说明

1. **选择棋子**：点击己方棋子，绿色圆点表示可移动位置，红色边框表示可吃子位置
2. **移动棋子**：点击可移动位置完成走棋
3. **重新开始**：点击「重新开始」按钮重置棋局
4. **悔棋**：点击「悔棋」按钮撤销上一步
5. **切换模式**：点击「切换为双人对战 / 切换为人机对战」切换游戏模式
6. **调整难度**：在「AI难度选择」中选择简单 / 中等 / 困难

## AI 算法说明

AI 采用 **Minimax + Alpha-Beta 剪枝** 为核心的搜索引擎，并包含以下增强（P4 轮）：

- **搜索深度**：简单 2 层、中等 4 层、困难 6 层（迭代加深，单次思考最长 5 秒，超时自动回退到上一层完整结果）
- **静态搜索（Quiescence Search）**：叶子节点继续延伸所有吃子与应将走法，消除地平线效应（最后一层吃子看不见回吃的战术盲区）
- **将军延伸**：被将军的节点额外搜索一层，应将序列不被截断
- **伪合法生成 + 懒合法性验证**：走法先生成后验证（配合剪枝，绝大多数走法在验证前即被裁剪），大幅减少每节点开销
- **反向射线攻击检测**：从目标格向外扫描攻击者，替代全盘遍历，单次检测快数倍
- **增量评估**：子力 + 位置价值表分数随走子增量维护，叶子评估降为 O(1)
- **mate 距离评分**：优先进更快将死 / 更慢被将死（含困毙）
- **重复局面感知**：搜索中把长将循环与对局历史重复局面按和棋估值，优势时避免自我重复送和
- **置换表 + 移动排序**：Zobrist 散列置换表（mate 分数按 ply 校正）、TT 走法置顶 + MVV-LVA 吃子排序 + 杀手走法 + 历史启发

## 自动化测试

`node test-engine.js` 可运行引擎测试套件（无任何依赖），覆盖：

- 攻击检测 / 懒合法性 / 增量评估 与参考实现的一致性（数十万例随机局面比对）
- 战术能力（一步将死、吃悬子、困毙杀）
- 搜索不变量（棋盘 / 行棋方 / 增量分在搜索后完全还原）
- 各难度性能基准

浏览器控制台亦可通过 `window.__bishopEngine` 访问引擎内部状态用于调试。
